# 声音来源与处理

旁白：MiniMax Audio 网站，在用户已登录的 Chrome 会话中分十段生成。使用 speech-2.8-hd，「温润青年」，语速 1、音调 0、音量 1；下载格式为无水印 WAV。原始下载留存在 assets/audio/01.wav 至 10.wav，原文件不做覆写。

音乐与音效：scripts/soundtrack.py 在远端使用固定随机种子 1021 与 NumPy 程序合成。旋律、和声、软脉冲、呼吸过渡、更新玻璃音皆由公式生成，无其他作者的音乐片段或采样。129 BPM，4/4；和弦每 32 拍变化，镜头停靠与章节边界使用同一拍点体系。滑翔机四次变化使用实际语音时间标记独立对齐。

混音：旁白先作 70 Hz 高通与 14.5 kHz 低通并归一化到 -19 LUFS；音乐由旁白实际包络自动衰减。双遍响度处理输出 48 kHz / 24 bit / stereo 母带，目标 -16 LUFS、-1.2 dBTP。交付 MP4 从无损母带编码为 AAC 320 kb/s；视频流不重复编码。交付文件会重新测量响度并完整解码校验，实际测量见 output/quality-report.json。

原始母带、旁白、音乐与音效分轨均在 output/ 与 output/stems/，可继续重混。没有使用 Suno，选择程序合成以保证拍点、音效和代码时间轴完全可重现。
