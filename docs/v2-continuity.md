# V2 · 连续生长

V2 保持 V1 的台本、旁白时序、音乐、音效、字幕和总时长。重写视觉演出，不修改 `film.html` / `src/film.js` 或 V1 成片。V2 入口是 `film-v2.html`，场景代码是 `src/film-v2.js`，解析运动函数在 `src/motion-v2.js`。

## 动作与渲染

- 镜头的主要推拉与对数缩放使用 minimum-jerk 五次曲线，端点速度与加速度为零；进场、分叉用快速启动后减速的曲线。
- 不使用累计积分、系统时钟、随机数、CSS 动画或逐帧状态。跳转、倒序调用、重载与多工作进程都应得到同一画面。
- 连续运动依据快门内的预估位移选择 1–8 次时间采样。`motionBlur` 与 `maxMotionBlur` 均设置为 8：Multiplane 0.3.8 的 `blurAt` 实际只能降低基础采样数，不能提升它。多采样由渲染器在线性光下合成，快门为半帧。
- 画布以设备像素比创建 backing store，4K 从矢量和模拟数据直接绘制；没有把 1080p 成片放大为 4K。
- 预览是 1920×1080 / 30 fps；最终是 3840×2160 / 60 fps。总时长约 355.35 秒。
- 音频直接从 V1 MP4 复制 AAC 数据包，包含全部旁白、音乐与音效。打包时比较音频数据的 SHA-256；不重新合成或编码音频。原始 AAC 流已封装在工程的 `assets/audio/v1-master.m4a`，连同来源校验值一并归档，重建 V2 不依赖 V1 的视频画面。

## 复现

在远端仓库根目录运行：

```sh
scripts/run.sh node scripts/test-simulation.cjs
scripts/run.sh node scripts/test-v2.cjs
sh scripts/render-v2.sh
```

渲染脚本进行检查、4K 渲染和打包。若没有事先生成 1080p30 预览，打包器会从 4K 成片生成该版本。封面来自 `cover-v2.html`，可用 `multiplane stills --at 0 --scale 2` 重建。

对比页在 `output/v2/index.html`，V1 在 `output/index.html`。对比页只播放一份音轨，两段视频保持同步。`output/v2/quality-report.json` 保存实际渲染采样统计、检查结果和音频校验值。所有交付文件校验值见 `output/v2/delivery-manifest.json`。
